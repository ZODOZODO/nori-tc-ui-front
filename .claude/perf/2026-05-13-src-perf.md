#### P0-1. [UX] Skeleton UI 부재 — 로딩 중 흰 화면
- 근거: Grep `Skeleton|skeleton|animate-pulse` → 0건
- 현상: 페이지 진입 시 데이터 도착 전까지 `<TableBody>` 가 비어있거나 화면이 흰색. 사용자 "멈춘 것" 으로 인식.
- 권장 변경: 각 페이지/테이블의 `isLoading === true` 분기에 skeleton 표시
  ```tsx
  {isLoading ? (
    <div className="space-y-2">
      {Array.from({ length: 10 }).map((_, i) => (
        <div key={i} className="h-8 animate-pulse bg-[#E5EDE9] rounded" />
      ))}
    </div>
  ) : (
    <Table>...</Table>
  )}
  ```
- 효과: 체감 응답성 ↑↑↑ (네트워크 시간은 동일하지만 사용자가 "동작 중" 으로 인식)
- 위험: 거의 없음. 디자인 토큰 통일 작업 동반 권장.
- 적용 범위: 모든 테이블 컴포넌트 19개 ([축 3 가상화 후보 목록 참고](#))

#### P0-2. [Query] `placeholderData: keepPreviousData` 미사용
- 근거: Grep `placeholderData|keepPreviousData|initialData` → 0건
- 현상: 페이지 전환 시 query key 가 바뀌면 데이터가 `undefined` 로 초기화 → 빈 테이블 → fetch 완료 후 채워짐
- 권장 변경: 모든 페이징/필터 기반 useQuery 에 옵션 추가
  ```ts
  import { keepPreviousData } from '@tanstack/react-query'

  return useQuery({
    queryKey: eqpQueryKeys.list(filters),
    queryFn: () => eqpApi.getList(filters),
    placeholderData: keepPreviousData,  // ← 추가
    staleTime: 60_000,
  })
  ```
- 효과: 페이지 전환 / 필터 변경 시 이전 데이터 유지하면서 새 데이터 fetch. 빈 화면 사라짐.
- 위험: 사용자가 잠깐 stale 데이터 보게 됨 (loading state 로 표시 권장)
- 적용 우선순위 hook: useEqpList, useModelList, useDeployHistoryList, useUsers, useGroups, useBusinessDlq, useGatewayDlq, useQuarantine, useRepairTasks, useDeployRegisterTargets

#### P0-3. [Query] 메뉴 hover 시 `queryClient.prefetchQuery` 부재
- 근거: Grep `prefetchQuery` → 0건
- 현상: 사용자가 메뉴 클릭 → 그 시점에 fetch 시작 → 응답 대기. 클릭 ~ 응답 사이 시간이 그대로 체감.
- 권장 변경: AppTopBar 메뉴 항목에 onMouseEnter prefetch 추가
  ```tsx
  // src/shared/components/AppTopBar.tsx
  const queryClient = useQueryClient()

  <NavLink
    to="/eqp"
    onMouseEnter={() => {
      queryClient.prefetchQuery({
        queryKey: eqpQueryKeys.list({}),
        queryFn: () => eqpApi.getList({}),
        staleTime: 60_000,
      })
    }}
  >
    설비
  </NavLink>
  ```
- 효과: 사용자 hover 200~500ms + 클릭까지 → 그 시간에 fetch 완료되어 클릭 시 즉시 표시. 페이지 전환 체감 큰 폭 개선.
- 위험: hover 만 하고 안 들어가도 fetch 발생 (네트워크 약간 증가). 자주 쓰는 메뉴만 적용 권장.

#### P0-4. [Query] `persistQueryClient` 미사용 — 새로고침 시 매번 빈 상태
- 근거: Grep `persistQueryClient|PersistQueryClientProvider` → 0건
- 현상: 페이지 새로고침 / 재방문 시 캐시 휘발 → 다시 fetch
- 권장 변경:
  ```bash
  npm install @tanstack/react-query-persist-client @tanstack/query-sync-storage-persister
  ```
  ```tsx
  // src/app/providers/AppProvider.tsx
  import { PersistQueryClientProvider } from '@tanstack/react-query-persist-client'
  import { createSyncStoragePersister } from '@tanstack/query-sync-storage-persister'

  const persister = createSyncStoragePersister({
    storage: window.localStorage,
    key: 'nori-tc-ui-cache',
  })

  export function AppProvider({ children }) {
    return (
      <PersistQueryClientProvider
        client={queryClient}
        persistOptions={{ persister, maxAge: 1000 * 60 * 30 }}
      >
        {children}
        <ReactQueryDevtools initialIsOpen={false} />
      </PersistQueryClientProvider>
    )
  }
  ```
- 효과: 재방문 시 즉시 표시 + 백그라운드 새 데이터 fetch (stale-while-revalidate)
- 위험: localStorage 5MB 한계. 큰 데이터 (live-map 이미지 등) 는 캐시 제외 dehydrateOptions 필요. 보안 민감 데이터 (개인정보) 도 캐시 제외 검토.
